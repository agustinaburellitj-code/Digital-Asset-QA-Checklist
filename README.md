# Digital Asset QA Checklist

A small static web tool for reviewing digital production assets before handoff. It helps organize asset details, QA checks, issues found, and final notes in a copy-ready summary.

## Focus

- Simulates a junior digital production QA checklist
- Supports asset review, file naming checks, export readiness, and handoff notes
- Keeps the interface clean, professional, and easy to use

## Features

- Asset details form with project, platform, format, size, version, and status
- QA checklist with common production review points
- Notes for issues found and final handoff comments
- Generate a copy-ready QA summary
- Copy summary to clipboard with one click
- Optional QA Mode notes section

## QA mindset demonstrated

This tool is built for a junior profile with a focus on review discipline: clear labels, step-by-step checks, human review reminders, and an exportable handoff summary. It avoids unnecessary complexity and highlights preparation before delivery.

## How to run

1. Open `index.html` in your browser.
2. Fill the asset form and select the checklist items.
3. Click **Generate QA Summary** to see a formatted review summary.
4. Click **Copy Summary** to copy the text to clipboard.
